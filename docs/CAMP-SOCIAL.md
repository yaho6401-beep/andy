# 별빛 캠핑장 — 소셜 기능 미리보기

## 완료한 기능

- 모닥불별 최대 6명, 전체 최대 20명. 빈 모닥불 배치와 모닥불 사이 이동.
- 이동, 근접 착석·일어나기, 중복 착석 방지.
- 모닥불 대화와 착석자 대화, 아바타 말풍선, 인사·박수·하트.
- 매일 바뀌는 대화 주제와 진행자의 당일 질문 변경.
- 조용히 듣기, 음소거, 사용자 차단, 신고 및 진행자 관리 기능.
- 기본 욕설·반복 전송 방지. 기본 필터는 모든 유해 표현을 탐지하지는 못한다.
- 3D 미지원 브라우저의 2D 대체 화면.

## 검증

- 기존 홈페이지 자동 검사 19개 통과.
- 기존 공간과 캠핑장 자동 검사 29개 통과.
- 빌드와 배포 패키징 성공.
- 실제 미리보기 접속 20개가 모닥불별 6·6·6·2명으로 배치되었고, 정원 초과 입장은 거절됨.
- 동시 착석 요청 중 하나만 성공. 채팅·음소거·양방향 차단·듣기·신고·권한 제한을 확인함. 검사 후 테스트 접속 20개를 모두 종료함.
- 배포 브라우저에서 입장, 키보드 이동, 착석, 채팅 전송, 듣기 모드, 일어나기, 다른 모닥불 이동, 접속 종료를 확인함.
- 위 브라우저 검수는 2D 대체 화면에서 진행함. 3D 실제 렌더링, 휴대폰 FPS·터치 조작, 장시간 동시접속 부하는 별도 검수가 필요함.

## 변경 범위 및 다음 단계

캠핑장 화면·전송·서버·검증 파일을 추가하고 기존 공용 코드의 이동·좌석 처리 확장 지점을 마련했다. 기존 기능의 기본 동작은 유지한다. 자세한 변경 파일 목록은 변경사항 화면에서 확인한다.

운영 홈페이지와 기존 커뮤니티는 배포하지 않았다. 미리보기 기능만 배포했다. BLUE HORIZON 연결은 없다.

다음 단계는 오늘의 문장 관리, 개인 책장, 향기 태그다. 향기나무와 응원 게시판은 그 이후에 진행한다.
