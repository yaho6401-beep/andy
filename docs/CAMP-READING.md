# 별빛 캠핑장 — 3D 실행 보완과 책 콘텐츠

## 변경된 동작

- 3D 실행 시 가벼운 GPU 설정을 먼저 시도하고, 사용할 수 없으면 기본 설정을 시도한다.
- 그래픽 미지원과 공간 구성 오류를 구분해 표시하고, 설정 화면에서 3D 다시 시도를 제공한다. 3D 연결이 끊기면 대화를 유지한 채 2D 대체 화면으로 전환한다.
- 한국 시간 자정에 바뀌는 오늘의 문장, 저자·출처 표시, 감상 기록, 문장 저장, 다섯 가지 향기 태그를 제공한다. 초기 문장은 이 공간을 위해 작성한 창작 문장이다.
- 개인 책장에 문장 카드, 감상, 읽은 책 제목·저자·짧은 감상을 보존한다. 기본 비공개이며 공개한 기록만 함께 읽기와 공개 감상에 표시한다.
- 관리자는 문장을 등록·수정·예약하고 공개 감상을 숨길 수 있다. 문장 출처와 이용 근거를 함께 기록한다.
- 책장은 캠핑장 접속이 끝나도 같은 브라우저에서 다시 불러온다. 다른 기기나 브라우저 데이터 삭제 후의 자동 복원은 지원하지 않으며 화면에 안내한다.

## 검증

- 기존 홈페이지 자동 검사 19개 통과.
- 기존 공간·소셜·모델과 신규 그래픽·책장 자동 검사 36개 통과.
- 실제 미리보기에서 오늘의 문장·출처·태그, 문장 중복 저장 방지, 비공개 감상·책 기록, 다른 사용자 수정·삭제 거절, 공개·비공개 전환, 책장 재조회, 관리자 접근 제한을 확인했다. 테스트로 만든 기록만 정리했다.
- 빌드와 패키징 성공. 실제 브라우저 검수 결과는 추가 기록한다.

## 변경 범위

캠핑장 그래픽 초기화, 문장·책장 화면, 책 콘텐츠 처리, 관련 자동 검사와 미리보기 준비 파일을 추가했다. 기존 조향 데이터와 운영 홈페이지는 변경하지 않는다. 운영 배포는 진행하지 않는다. 기존 소셜 미리보기 서버는 유지하고 책 콘텐츠는 별도 미리보기에서 제공한다.

실제 3D 화면의 시각 검수, 물리 휴대폰 FPS·터치, 관리자 실제 계정의 등록 과정은 추가 검수가 필요하다. 향기나무와 응원 우체통은 다음 단계다.
