# 손전등 탐색과 같은 바다의 크루즈

손전등을 40도·12m에서 64도·17m로 넓혔고 광량을 27에서 58로 높였습니다. 그림자 없이 스폿 조명 하나와 옅은 광선 하나를 재사용합니다. 장애물 앞에서는 빛의 도달 거리를 줄입니다.

실제로 승인된 캠핑장 이동 중 손전등을 켜고 걷는 경우만 서버가 탐색을 누적합니다. 16m 이상·최소 12초 간격으로 28% 확률을 판정하고, 발견 후 2분 동안 재발견을 막습니다. 참치캔·컵라면을 각각 두 개까지 개인 꾸러미에 보관합니다. 컵라면이 있어야 온유 할아버지 가까이에서 뜨거운 물을 받을 수 있습니다. 간식을 먹으면 10분 동안 육지 이동속도 2배를 적용합니다. 기존 간식 효과와 곱해 과도하게 빨라지지 않으며, 젖은 옷의 감속은 유지합니다. 앉기·수영·구조·항해 중에는 탐색하지 않습니다. 임의 아이템·시간·확률 입력은 신뢰하지 않습니다.

조각배는 기존 항로와 충돌 검증을 유지하면서 해변–섬 11.5초, 해변–크루즈 15초, 섬–크루즈 6.5초로 단축했습니다. 모든 항로에서 생선 효과를 받은 수영보다 빠릅니다.

BLUE HORIZON은 향기마을의 `createAvatar`·`animateAvatar`와 같은 GLB 자산을 사용합니다. 여덟 캐릭터의 머리·옷과 걷기·앉기·인사가 이어집니다. 갑판 우드결, 라운저, 황동, 구명환, 화분, 식당 식기를 추가하고, 고정 가구는 재질별로 합칩니다. 시간대 조명과 바다의 먼 물결을 다듬고 기존 NASA 달 텍스처를 재사용했습니다. 선수에는 실제 캠핑장, 선미에는 실제 향기마을을 촬영한 원경이 보입니다. 원경 두 장 약 55KB, 다섯 공간 약 50~60 draw calls를 확인했습니다. 실제 휴대폰 30FPS 보장을 뜻하지는 않습니다.

독립 원본 `G:/github/blue-horizon`은 변경하지 않습니다. 서비스에 통합된 `archive/cruise`만 개선합니다. 크루즈는 기존과 같은 싱글플레이이며 향기마을의 공용 접속은 유지합니다.

검증: 서버 단위·통합 검사, 30인 WebSocket 접속 검사, 격리된 브라우저에서 실제 이동 → 발견 → 온유에게 물 받기 → 먹기 → 효과 확인, 크루즈 5공간·승선·복귀, 320/390px 세로·844px 가로·1080px 화면. 공개 환경은 별도 점검하고 결과는 운영 데이터와 분리해 보관합니다.
