# 크루즈 독서와 연결된 배

빌린 책은 기존 `bookscents-library-loan`을 그대로 읽습니다. 대여 정보가 있는 방문객에게만 BLUE HORIZON 상단에 ‘빌린 책’ 버튼을 표시합니다. `TentReading`으로 성경전서·세계명작·한국 고전을 읽으며 기존 읽던 장, 글자 크기, 책갈피, 전체화면, 내 수첩으로 문장 옮기기를 공유합니다. 읽기는 로그인 없이 가능하고, 개인 수첩 저장은 기존 계정 권한을 유지합니다. 새 책으로 바꾸는 10분 간격도 그대로입니다.

이전에는 17m 단위의 공간 그룹을 같은 위치에서 바꿔 보여줬습니다. 이제 약 73m 길이의 한 배에 선수·메인 갑판·선미를 실제 통로로 이어 배치했습니다. 선교·식당은 7.2m 높이의 상층이며 좌·우현의 24단 계단을 통해 오갑니다. 연결 복도, 난간, 지지 기둥, 계단 받침과 층별 입구를 추가했습니다.

공간 버튼은 이동 경로를 찾아 직접 걸어갑니다. 조이스틱이나 방향키를 움직이면 자동 보행을 중단합니다. 걸으면서 시야와 높이가 연속적으로 변하며 독서창·수첩·로그인 창에서는 이동하지 않습니다. 상층에 바로 나타나는 순간이동을 사용하지 않습니다. 선수 쪽에는 캠핑장, 선미 쪽에는 향기마을 원경이 실제 다른 방향에 놓입니다.

`ship-layout.js`의 같은 좌표를 통로·계단 렌더링과 보행 검증에 사용합니다. 미세 구간까지 바닥을 검사해 계단 모서리에서 멈추거나 다른 층으로 튀는 문제를 방지합니다. 고정 오브제는 배 전체에서 재질별로 합쳐 그리며, 마을 씬과 별도의 번들·렌더러를 유지합니다. 독립 원본 Blue Horizon, 공용 라운지 서버, 데이터베이스는 수정하지 않습니다.

검증: 전체 321개 Node 검사, 5공간의 25개 왕복 경로, 계단 중간 높이와 모서리 보행, 실제 모바일 UI의 대여 → 크루즈 읽기 → 책갈피/글자 크기/문장 옮기기 → 캠핑장 복귀. 320/390px 세로·844px 가로·1080px 화면에서 확인합니다. 공개 배포의 결과는 별도 로컬 보고서에 보관합니다.
