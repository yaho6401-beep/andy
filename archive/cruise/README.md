# BLUE HORIZON · 책과향기 연결

별빛 캠핑장 해변·작은 섬의 조각배 옆에서 **크루즈 찾아가기**를 선택한다. 서버가 출항과 항로를 검증하며 해변에서는 약 15초, 섬에서는 약 6.5초 후 정박한 크루즈에 도착한다. 도착 후 승선하거나 출발했던 선착장으로 돌아갈 수 있다.

승선하면 `/archive/cruise/`를 새 페이지로 연다. 마을의 WebGL과 공용 접속은 정리되고, 크루즈 코드만 별도로 불러온다. 메인 갑판·선수·선미·선교·식당, 조타·망원경·시간대·소리는 기존 로컬 BLUE HORIZON 시연 코드에서 가져왔다. 원본 `G:/github/blue-horizon` 폴더는 수정하지 않았다. 출처와 원본 해시는 `source-info.json`에 기록했다.

크루즈는 **1인 체험**이다. 마을의 30명 공용 접속과 별개이며 크루즈 내부 다중 사용자 동기화는 제공하지 않는다. 닉네임과 의상·머리색은 같은 출처의 기존 프로필을 사용한다. 인증 토큰이나 개인 정보를 URL에 넣지 않는다. 돌아가기 버튼은 고정된 캠핑장 해변으로만 연결된다. 공용 공간에서 보유한 물품·기록은 기존 서버 저장 방식을 유지한다.

`npm run build`가 Three.js를 기존 잠금 버전으로 묶어 배포하며 외부 CDN을 요구하지 않는다. 마을을 열 때 크루즈 번들은 다운로드하지 않는다. `soloPreview=1`은 개발용 독립 체험 모드이고 복귀 시에도 유지된다.

검증: `node --test tests/cruise-voyage.test.mjs`, `node tests/cruise-voyage.browser.mjs`. 브라우저 검증은 격리된 체험에서 항해 시간만 이동시켜 승선·취소·공간 이동·방향키·복귀 및 320/390px 모바일·가로 화면을 확인한다. 실제 운영 API 항해는 별도로 실시간 검증한다.

그래픽 개선: 향기마을과 동일한 GLB 아바타·헤어·의상·걷기·앉기·인사 애니메이션을 사용합니다. 티크 우드결, 라운드 라운저, 화분, 구명환, 황동 디테일과 식당 테이블 세팅을 추가했습니다. 고정 오브제는 재질별로 합쳐 렌더링합니다. 선수에서는 실제 캠핑장, 선미에서는 실제 향기마을을 촬영한 경량 원경이 보입니다. 달은 기존 NASA LRO 텍스처를 재사용합니다.
