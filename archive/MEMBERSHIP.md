# 책과향기 회원 이용 흐름

둘러보기·전시 관람·이동·불멍·장작과 간식 굽기는 비회원도 이용한다. 가상 카페 주문, 공개 대화, 포스트잇 작성·삭제, 문장과 향 기록 저장에는 휴대폰 번호 + 비밀번호 로그인을 사용한다. 닉네임은 가입 시 정하며 전화번호는 다른 참가자에게 공개하지 않는다. 문자 발송이나 번호 소유 인증은 하지 않는다.

홈페이지 상단 또는 가상공간의 프로필 설정에서 로그인한다. 보호된 기능을 먼저 누르면 해당 위치에서 로그인하고 이어서 사용할 수 있다. 취소하면 둘러보기로 돌아간다. 독서 시작·풍경 감상에는 로그인을 요구하지 않는다.

새 독서·방울 수 조향 기록은 계정에 비공개로 저장한다. 기존 브라우저 기록은 원래 키에 보존하며 본인이 명시적으로 가져오기 버튼을 눌렀을 때만 복사한다. 기존 닉네임 기반 향 기록장은 별도 버튼으로 계속 열 수 있다. 새 휴대폰 회원의 메인향 기록은 기존 향 기록장 테이블과 관리자 화면을 재사용한다.

서버는 별도 비공개 스키마 workshop_private를 사용한다. 공개 API 역할에 스키마 및 테이블 접근 권한을 부여하지 않는다. 비밀번호는 개별 salt와 PBKDF2-SHA256 600,000회로 해시한다. 30일 세션은 같은 출처의 HttpOnly / Secure / SameSite=Lax 쿠키에만 저장하며 localStorage에 인증 정보를 보관하지 않는다. 10분 접근 티켓을 사용하고, 공유 라운지 서버는 글·주문 요청마다 현재 티켓과 세션을 검증한다. 호스트 및 성인 모임 승인은 회원 가입과 독립적이다.

회원 탈퇴에는 현재 비밀번호를 요구하며 새 회원정보와 그 계정의 기록을 삭제한다. 이전 닉네임 계정과 기록은 자동 삭제하지 않는다. 문자 인증을 사용하지 않으므로 비밀번호 자동 재설정은 제공하지 않는다.

배포 전 `node scripts/prepare-account.mjs`와 `node scripts/prepare-edge.mjs`로 서버 의존성을 동기화하고, 빌드·회원 테스트·실제 서버 격리 테스트·모바일 브라우저 테스트를 실행한다. Blue Horizon은 변경 대상이 아니다.
