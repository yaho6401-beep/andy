# 내 수첩

독서창 → 문장 고르기 → 문장/절 선택 → 내 수첩에 옮기기. 일반 책은
`Intl.Segmenter`의 문장 단위, 성경은 절 단위로 선택한다. 여러 항목은
원문 순서대로 모으며 한 페이지의 문장은 4,000자까지 저장한다.
‘드래그한 글 옮기기’로 부분 선택도 가능하다. 직접 옮겨 적기에서는
현실의 책에서 복사한 글, 출처, 쪽수, 개인 생각을 입력할 수 있다.

내 수첩은 독서창, 고전 서가, 계정 메뉴와 `/notebook/`에서 열 수 있다.
저장한 페이지는 검색, 수정, 개별 삭제, TXT 내려받기가 가능하다.
본문과 출처/판본 안내는 함께 보존하며 공개 게시판으로 전송하지 않는다.

저장은 기존 HttpOnly 세션 `/api/workshop-account`를 사용한다.
`workshop_private.member_records`의 `kind=notebook`으로 사색 일지와 분리한다.
인증된 회원 ID와 종류가 모든 읽기/쓰기/삭제 조건에 포함되고, 클라이언트가
전달한 소유자 ID는 사용하지 않는다. 종류별 500개 제한을 그대로 적용한다.
수첩 원문을 localStorage에 복제하지 않으며 로그아웃/계정 변경 시 메모리를
비우고 창을 닫는다. 계정 전환 중 완료된 요청 결과도 폐기한다.

백엔드를 수정하면 `node scripts/prepare-member.mjs`를 archive 폴더에서
실행해 Edge Function의 동일한 유효성 검사를 동기화한다.
배포 순서는 notebook 허용 제약조건 확장 → workshop-account 배포 → 웹이다.
기존 DB 행, 읽기 기록, 조향 기록과 접근 권한은 변경하지 않는다.
