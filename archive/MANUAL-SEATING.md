# 앉기와 NPC 대화

- 의자·벤치 근처에서는 우측 `앉기`만 활성화된다. 프레임 루프에서 `sit`을
  자동 전송하지 않는다. 빈 자리/거리/권한은 기존 서버에서 다시 검사한다.
- 모닥불 통나무와 멀리서 불멍 벤치는 우측 `앉기` 대상에서 제외한다.
  가운데 불멍 버튼 한 번으로 가까운 자리로 이동 → 앉기 → 불멍을 시작한다.
  먼 벤치 가까이에서는 해당 벤치를 선택하고, 다른 곳에서는 모닥불 통나무를
  선택한다. 버튼을 누르지 않으면 가까이 가도 앉지 않는다. 수동 이동·다른
  화면 열기·방 이동은 진행 중인 불멍 자리 이동을 취소한다.
- 서가와 텐트 상호작용 버튼도 우측 조작 영역에 함께 배치해 겹침을 방지한다.
- 텐트지기 일상 대화와 큐레이터 대화는 주제에 맞는 자체 작성 본문 6개,
  도입 4개, 맺음 4개를 조합한다. 주제별 96가지이며 최근 12개 답변은 피한다.
- 추천 질문은 대화창을 새로 열 때 3개만 추리고 직전 3개와 겹치지 않게 한다.
  성경 대화도 추천 예시 3개를 갱신하며, 실제 성경 본문·낱말 자료는 유지한다.
- 바리스타의 메뉴 인사는 12개 중 바꾸며, 메뉴 탭만 바꿀 때는 인사를 유지한다.
- 대화 선택은 로컬에서 처리하며 외부 AI 서비스·유료 API를 추가하지 않는다.

검증: `node --test tests/seat-dialogue.test.mjs`.
로컬 개발 서버 실행 후 `node tests/seat-npc.browser.mjs`로 화면 흐름을 점검한다.
다른 주소는 `SEAT_NPC_BASE` 환경변수로 지정한다. 화면 테스트는 개인 시연
모드와 임시 메모리 데이터만 사용하며 운영 API 기록과 방문분석 전송을 막는다.
