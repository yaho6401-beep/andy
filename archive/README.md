# BOOKS & SCENTS ARCHIVE — 로컬 시연판

접속: http://127.0.0.1:4173/archive/
홈페이지 흐름: http://127.0.0.1:4173/ → 커뮤니티 라운지 → 3D 아카이브 시연판 입장. 로컬 서버는 이 홈페이지 사본의 운영 API 연결을 차단합니다. 기존 신청서·메모·게임 쿠폰은 로컬 시연에서 사용할 수 없습니다. 3D 시연은 별도의 메모리 서버만 사용합니다.

## 실행
개발 PC에서 archive/시연판 실행.cmd 실행 후 위 주소 접속. 이미 서버가 켜져 있으면 링크만 여세요. 서버는 127.0.0.1에만 바인딩하므로 다른 PC나 휴대폰에서는 접속할 수 없습니다. 외부 공개/운영 배포는 진행하지 않았습니다.

1. 닉네임, 남성4종·여성4종 캐릭터, 머리·의상 색을 고르고 성인·존중 동의 후 입장.
2. 왼쪽 조이스틱 또는 WASD/방향키로 이동. 건물 벽과 가구는 통과할 수 없습니다.
3. 햇살 정원에서 산책길을 따라 건물 문으로 걸어가면 로비에 들어갑니다. 로비 왼쪽은 향기 아카이브, 오른쪽은 북라운지, 안쪽은 향기카페입니다. 각 공간의 문으로 걸어가면 다시 로비로 돌아옵니다. 오른쪽 전시 목록 버튼은 설명을 열며 공간 이동은 하지 않습니다.
4. 대화와 인사·박수·하트·앉기, 취향 프로필을 사용하세요.
5. 다른 브라우저 또는 시크릿 창에서 별도 참가자로 입장하면 실제 아바타·대화가 동기화됩니다.

## 진행자 시연
archive/.local/host-key 파일의 실행할 때마다 바뀌는 테스트 키를 복사하고, 입장 화면의 ‘로컬 진행자로 테스트하기’에 입력합니다. 기존 관리자 비밀번호와 다릅니다. 진행자는 질문·타이머·진행 단계·대화 그룹·콘텐츠·참가 상태·차단을 관리합니다. 5단계 마무리에 비공개 호감 선택이 열리고, 서로 선택하고 연락 연결에 모두 동의한 결과만 진행자에게 표시됩니다.

## 시연 제한
3D 참가자·대화·취향은 서버 메모리의 테스트 데이터이며 서버 재시작 시 초기화됩니다. 책장·카페 포스트잇은 archive/.local/reader-notes.json에 로컬 보관되어 재실행 후에도 남습니다. 운영 데이터베이스에는 저장하지 않습니다. 기존 신청서/연락처와 연결되어 있지 않습니다. 이메일 인증 및 운영 모임 권한은 아직 연결하지 않았습니다. 운영 도메인에서는 입장을 차단합니다. 이 코드를 그대로 운영 서비스로 공개하면 안 됩니다.

## 책장과 카페 업데이트
기본 모임 안내는 접혀 있으며 좌측 위 버튼으로 펼칩니다. 우측 위 ⛶ 버튼은 브라우저 전체화면을 전환합니다. 진열장과 책장에 다가가면 아래쪽에 작은 발견 카드가 뜹니다. 책장은 실제 도서 목록, 직접 작성한 작품 소개와 대화 질문, 작품 정보 출처를 제공합니다. 포스트잇에서 추천/소개/한줄을 골라 120자 메모를 붙이고 본인 메모를 삭제할 수 있습니다. 한 페이지9장입니다. 향 문장은 창작임을 표시하며 소설 본문·번역문이나 표지는 복제하지 않았습니다.

## NPC 카페·착석·대화
향기카페 바리스타나 박물관 큐레이터 가까이 가면 대화를 먼저 건넵니다. 카페 메뉴는 커피/차/에이드/디저트 각5개, 총20개입니다. 가상 메뉴 한 개를 고르면 서버시간30초 뒤 닉네임을 부릅니다. 카운터에서 받아 가까운 테이블의 ‘받아온 메뉴 테이블에 놓기’ 버튼을 누르면 다른 참가자도 볼 수 있게 올라갑니다. 자기 메뉴는 앉은 자리의 ‘내 메뉴 정리하기’로 치울 수 있습니다.
빈 의자·소파·벤치 가까이에서 이동을 멈추면 약0.7초 후 자동으로 앉습니다. 이동 조작이나 ‘사뿐히 일어나기’로 일어납니다. 다른 사람이 앉은 자리는 사용할 수 없습니다. 총28개 자리의 접근/착석/일어서기를 검증했습니다.
앉으면 ‘공상 💭’이 나에게만 보이며 ‘공상 · 나만의 생각’에서 문구를 설정하거나 끌 수 있습니다. 개인 생각은 브라우저 localStorage에만 보관하고 서버·다른 참가자에게 전송하지 않습니다.
대화창에서 공개 대화/귓속말/큰소리를 고릅니다. 공개 대화는 현재 공간, 귓속말은 전송 시점 같은 테이블·같은 벤치에 함께 앉은 사람에게만 전달됩니다. 큰소리는 현재 공간에 대형 말풍선으로 표시되며 입장당1회만 가능하고, 다른 공간으로 나갔다 다시 들어오면 초기화됩니다. 자리만 옮기는 것으로는 초기화되지 않습니다.
카페 주문·가상 메뉴 배치는 테스트 서버 메모리에 있으므로 서버 재시작 시 초기화됩니다. 실제 결제·상품 제공과는 연결되지 않습니다.


### 다양한 카페 좌석과 바리스타 대화
카페에 8인·6인 사각 테이블, 4인·2인 원형 테이블, 4석 바테이블을 배치했습니다. 총 카페24석, 전체36석입니다. 가구 모델·충돌·좌석·음료 배치를 같은 정의에서 생성합니다.
바에 앉아 대화창에서 귓속말을 선택하면 바 좌석 참가자와 가상 바리스타가 대화합니다. NPC는 간단한 규칙 기반 응답이며 AI 서비스에 연결하지 않습니다.
진행자로 로그인하고 카페에 들어온 뒤 진행자 메뉴 → ‘바리스타 자리에서 귓속말 대화하기’를 선택하면 NPC 위치로 이동합니다. 이 동안 NPC는 자동 응답을 멈추고 숨겨집니다. ‘사뿐히 일어나기’로 복귀합니다. 서버가 권한·공간·중복 점유를 검증하며, 바 이외 사용자에게 귓속말을 전달하지 않습니다.


### 公開 체험판 / 고객 반응 확인용
운영자 요청에 따라 public-demo 모드에서는 브라우저 내부의 1인 시뮬레이션을 사용합니다. 다른 고객·진행자와 실시간 연결되지 않으며, 대화·주문·공간 메모는 현재 방문에만 남습니다. 서버 권한 기능은 공개 모드에 제공하지 않습니다. 기존 로컬 WebSocket 모드와 구분합니다.
홈 커뮤니티 라운지 → /archive/. 솔로만 신청 버튼은 홈 라운지 아래에 분리했고 로비 신청 게시판에서도 같은 기존 신청 폼을 사용합니다. 신청 폼은 실제 기존 Edge Function에 전송되며 다른 체험객에게 공개하지 않습니다.
아카이브 조향대는 기존 catalog의 메인향72·단일향30 및 ScentStyle.describeBlend를 재사용합니다. 선택한 메인향1개와 복수 단일향을 메인 기록장으로 이어갈 수 있습니다.
큐레이터는 입구에서 떨어진 안쪽에 배치하고 입장 시 자동 모달을 제거했습니다. 음료는 서버/시뮬레이션이 방문자와 가장 가까운 빈 테이블 슬롯을 골라 배치합니다.
Vercel은 root vercel.json의 buildCommand로 archive 빌드 후 .release/customer-demo를 배포합니다. package-public.mjs는 공개 정적 파일만 모으고, 기존 미니게임이 참조하는 runner-engine.js를 보존합니다. 로컬 키·node_modules·서버 소스는 공개 산출물에 포함하지 않습니다. 신청 폼은 같은 출처 iframe으로 열리므로 X-Frame-Options는 SAMEORIGIN입니다.
